¿Cómo se actualiza la web?

Si trabajas sin GitHub, pulsa «Descargar JSON» y reemplaza el archivo data/catalogo.json del repositorio. Si conectas GitHub, usa «Publicar cambios en GitHub» para crear el commit desde aquí.

¿Cuándo se reflejan los cambios?

GitHub Pages puede tardar algunos minutos en publicar la versión nueva. Recarga la web cuando el despliegue haya terminado.
